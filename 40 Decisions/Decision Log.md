# Decision Log

## 2026-07-27 — Canonical memory architecture

**Decision:** Use Git-backed Obsidian as canonical memory, ChatGPT Work as the reasoning and production layer, and OpenClaw as the local automation layer.

**Reason:** This separates durable user-owned knowledge from model memory while preserving version history and enabling automation.

**Consequences:** Material changes should be committed; sensitive material requires classification; automatic writes begin in the inbox.
