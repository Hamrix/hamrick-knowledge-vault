# 1911 Encyclopaedia Britannica - Henry II

## Citation

“Henry II. of England,” *Encyclopaedia Britannica*, 11th ed. (1911), digitized at Wikisource, https://en.wikisource.org/wiki/1911_Encyclop%C3%A6dia_Britannica/Henry_II._of_England.

## Description

Historical encyclopedia biography of Henry II.

## Relevant extracts

- Identifies Henry II as son of Geoffrey Plantagenet, count of Anjou, and Matilda.
- Identifies Matilda as a daughter of Henry I.

## Reliability and limitations

This is an older secondary reference work and should not be used alone for disputed medieval genealogy. It independently agrees with the modern Archontology reference on this direct, well-established relationship.
