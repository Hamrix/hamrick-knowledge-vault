# The supplied Selby Manor PDF is not the represented 46-page evidence packet

## Claim

The supplied file `Selby_Manor_Evidence_Bundle_vFinal.pdf` contains 15 pages and does not contain the original records listed in its index as a 46-page evidence packet.

## Evidence supporting

- [[Legacy Selby Manor evidence bundle file audit]] records the file's page count, SHA-256 hash, metadata, and contents after direct inspection.
- The file contains no embedded attachments and omits the indexed certificates, archival scans, HMLR official copy, valuation, DNA evidence, and validation report.

## Evidence against

No evidence against the technical file findings was identified.

## Analysis

The file is valuable as a record of the project's drafted claims and intended evidence structure. It cannot be cited as though it contains the underlying exhibits because those exhibits are absent.

This finding does not establish that every indexed document is fictitious. It means each document must be obtained and authenticated separately.

## Confidence rationale

`confirmed`: based on direct technical and visual inspection of the supplied digital file.

## Public wording

Use: “A legacy 15-page draft bundle lists intended exhibits, many of which have not yet been supplied or authenticated.”

Do not use: “The complete 46-page certified evidence pack proves the claim.”
