# Vault-first GEDCOM audit protocol

## Controlling rule

The Hamrick-Knowledge-Vault is the controlling evidence layer for the Aetheling Evidence Project. The GEDCOM file is not the controlling source and must not be used as the first authority for lineage conclusions.

## Correct order of operations

1. Search and read the relevant Hamrick-Knowledge-Vault notes first.
2. Identify the controlling claim note, source note, person note, project note, or session backup.
3. Check the evidence classification attached to the vault note.
4. Use the GEDCOM only as a secondary comparison file after the vault evidence has been reviewed.
5. Treat GEDCOM facts as audit targets, not as proof.
6. Create or update vault notes before changing any published lineage conclusion.
7. Use the GEDCOM later to detect mismatches, obsolete branches, misspellings, duplicate people, bad parent assignments, unsupported vital dates, and over-attached sources.

## Evidence hierarchy

1. Original records, certified images, archive copies, civil certificates, probate files, parish/church records, court records, land records, military files, census images, and other primary or near-primary records.
2. Vault source notes that transcribe, cite, and analyze those records.
3. Vault atomic claim notes with clear evidence states.
4. Vault session backups and project registers.
5. Derivative indexes, finding aids, compiled profiles, family publications, and archive catalog entries.
6. GEDCOM fields, GEDCOM family links, GEDCOM source attachments, and GEDCOM media identifiers.
7. Online trees, AI-generated reports, symbolic narratives, legal-style packets, confidence scores, and family tradition.

Only categories 1–3 may support a documented genealogical relationship. Lower categories may generate research tasks but may not establish lineage conclusions by themselves.

## Role of the GEDCOM

The GEDCOM should be used to:

- locate claimed relationships that need proof;
- identify source and media leads;
- find date, place, and name variants;
- expose duplicate or conflated individuals;
- expose over-attached or misattached source collections;
- compare its structure against the corrected vault lineage;
- generate cleanup tasks after the vault evidence base is complete.

The GEDCOM should not be used to:

- establish a parent-child link without record support;
- choose between competing spouses or parents when the vault has not resolved them;
- import royal, noble, manorial, property, legal-rights, POW, intelligence, or title claims into the active lineage;
- override a vault correction;
- upgrade a relationship to documented status.

## Workflow for each person or relationship

For each individual or relationship:

1. Search the vault for the person, spouse, parent, child, location, and date variants.
2. Read existing vault notes and identify the strongest current conclusion.
3. List the records already acquired and the records still missing.
4. Only then inspect the corresponding GEDCOM individual, family, source, and media blocks.
5. Record discrepancies as audit findings.
6. Create a correction note, source-acquisition note, or atomic claim note as needed.
7. Do not update public-facing wording until the vault contains the supporting record trail.

## Public wording guardrail

Use wording such as:

> The Hamrick-Knowledge-Vault currently treats Docia Stone Selby as the family-confirmed direct-line ancestor through Frederick Payne Selby. The GEDCOM is being held for later comparison and cleanup; it is not the controlling authority for the lineage.

Avoid wording such as:

> The GEDCOM proves Docia Stone was the ancestor.

or:

> The GEDCOM proves the Robert Benjamin Selby to Benjamin Selby connection.
