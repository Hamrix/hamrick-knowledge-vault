# Vault Operating Manual

## Capture

All unclassified material enters `90 Inbox`. Captures should include:
- source or conversation origin;
- capture date;
- project association;
- privacy classification;
- suggested destination.

## Process

During processing:
1. remove duplicates;
2. separate facts from interpretations;
3. create atomic notes;
4. link them to a project index;
5. add source records;
6. record unresolved questions;
7. commit the changes.

## Review cadence

- Daily: process urgent inbox items.
- Weekly: update active-project state notes.
- Monthly: review stale claims, broken links, and unresolved contradictions.
- Quarterly: archive inactive projects and export a backup.

## Privacy levels

- `public`: suitable for publication.
- `internal`: ordinary private project material.
- `confidential`: sensitive personal or business information.
- `restricted`: never send to an AI service without explicit review.

Restricted material should be kept outside the Git-backed vault or encrypted separately.
