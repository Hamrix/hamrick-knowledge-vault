# Memory Policy

## Store in the vault

- durable preferences;
- project objectives and constraints;
- decisions and their rationale;
- verified facts;
- source citations;
- open questions;
- operating procedures;
- reusable prompts;
- current project state.

## Do not store automatically

- passwords, tokens, or recovery codes;
- precise financial account details;
- government identity documents;
- private health records;
- transient emotional statements;
- unverified personal allegations;
- copyrighted material copied in bulk.

## Memory hierarchy

- Native ChatGPT memory: convenience and personalization.
- ChatGPT Project: active working context.
- Obsidian vault: canonical, inspectable memory.
- Git history: record of changes and reversals.
