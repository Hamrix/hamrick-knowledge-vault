# Project-State Synchronization

A material genealogy change includes a direct-line edge changing confidence, a central identity correlation changing, a bridge becoming supported or contradicted, the earliest supported ancestor changing, or a public lineage statement becoming supportable or blocked.

For material changes inspect only affected:
1. source note(s);
2. atomic claim note(s);
3. person note(s);
4. relevant Aetheling state note;
5. Project Index;
6. project change log;
7. public inventory only when publication language changes.

If an edge weakens, preserve valid people, sources, and confirmed segments. Mark larger descents traversing that edge blocked/unproven rather than deleting history.
