# Research Strategy — Information Gain

## Vault first

Before web research:
- Project Index
- current project-state note
- relevant Claims
- relevant People
- relevant Sources
- prior negative searches/inventories

## Rank next records

Prioritize by ability to:

1. explicitly name parent/child;
2. distinguish same-name people;
3. resolve a known conflict;
4. identify heirs/associates;
5. replace derivative text with original image;
6. connect exactly one unsupported edge.

## Modern genealogy

High-value:
- probate
- civil vital records
- church registers
- deeds
- guardianship
- censuses with relationship fields
- marriage licenses/applications
- death certificates with informant analysis
- military/pension records
- court records

## Colonial

High-value:
- wills/administrations
- guardianship
- deeds
- land patents/surveys
- tax/assessment
- court minutes
- estate distributions

## Medieval

Follow `medieval-lineage-protocol.md`.

## FAN research

Friends, Associates, Neighbors can generate indirect evidence.

Association is not kinship without further proof.

## Stop broad search

Stop when new web results merely repeat:
- same tree
- same compiled genealogy
- same transcription
- same uncited narrative

Identify the archival target instead.
